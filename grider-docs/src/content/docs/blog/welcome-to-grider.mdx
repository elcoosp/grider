Before you can parse a spreadsheet screenshot or route cells to OCR, you need to know where the whitespace bands are. Pulling in OpenCV or an object-detection model just to find horizontal and vertical gutters adds gigabytes of dependencies for a problem that is mostly pixel arithmetic.

Grider finds row and column bands in pure Rust using adaptive thresholding and a single pass over pixel runs.

## The Goal

We wanted a Rust library and CLI (`grider` 0.3) that takes a raster image and returns a `Grid` of `Row` and `Column` bands tagged `Empty` or `Full`. It needed to handle both clean digital UI screenshots and unevenly lit scanned documents without manual per-image threshold tuning.

## How it works

Grider converts the image to grayscale, binarizes it into foreground and background pixels, and scans both axes to group contiguous runs.

## What it cost

Our initial implementation used `imageproc`'s generic adaptive threshold routines. Replacing that path with a custom streaming integral image made binarization 1.6× to 3.1× faster in our benchmarks while keeping bit-for-bit identical output. The trade-off is maintaining our own border-clamping math and work-size-gated band scheduler.

<Aside type="caution" title="Where this does not apply">
Grider assumes axis-aligned rectangular layouts. If a scanned page is rotated by even a few degrees, horizontal scan lines cross multiple text rows and collapse them into a single `Full` band. Deskewing must happen before passing the image to Grider.
</Aside>

## Getting started

```toml
[dependencies]
grider = "0.3"
image = "0.25"
```

```rust
use grider::{Grid, GridConfig};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let img = image::open("table.png")?;
    let grid = Grid::try_from_image_with_config(&img, GridConfig::default())?;
    println!("Detected {} rows and {} columns", grid.rows().len(), grid.columns().len());
    Ok(())
}
```

Follow the [tutorial](/tutorials/extract-your-first-grid/) to run the CLI and inspect a grid overlay.
