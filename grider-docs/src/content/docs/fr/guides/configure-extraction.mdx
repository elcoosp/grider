Ce guide montre comment piloter le pipeline d'extraction avec [`GridConfig`](/reference/grid-config/) — quels réglages déplacent la détection dans quelle direction, comment les valeurs invalides sont gérées, et quand recourir à chacun.

## Prérequis

- Grider ajouté à un projet Rust ([Installation](/guides/install/))
- Une image dont l'extraction de grille a besoin d'être ajustée

## Utiliser le builder

`GridConfig::builder()` part des valeurs par défaut et remplace un champ à la fois :

<Code lang="rust" code={`use grider::GridConfig;

let config = GridConfig::builder()
    .threshold_block_size(15) // adaptive threshold radius (min 3)
    .threshold_delta(0) // offset subtracted from the local mean
    .merge_threshold_ratio(0.9)
    .parallel(false)
    .build();

let grid = Grid::try_from_image_with_config(&img, config).expect("Failed to create grid");`} />

## Choisir le bon réglage

Utilisez ce tableau pour passer du symptôme au réglage :

| Symptôme | Réglage | Direction |
| :--- | :--- | :--- |
| Les bandes de contenu fusionnent avec leurs voisines | `merge_threshold_ratio` | Baissez-le (par exemple `0.5`) pour que moins de petites plages fusionnent |
| Les espaces filiformes divisent une bande logique en plusieurs | `merge_threshold_ratio` | Augmentez-le (par exemple `0.9`) |
| La fenêtre ignore les détails fins | `threshold_block_size` | Baissez-le (minimum `3`) |
| Le bruit d'arrière-plan compte comme du contenu | `threshold_delta` | Baissez-le (les valeurs négatives rendent le seuil plus strict) |
| Le contenu pâle disparaît | `threshold_delta` | Augmentez-le (les valeurs positives sont plus permissives) |
| Exécutions monothread reproductibles | `parallel(false)` | Désactiver le parallélisme |

La liste complète des champs avec types, valeurs par défaut et règles de contrainte se trouve dans la [référence `GridConfig`](/reference/grid-config/).

## Comprendre le contrat de contrainte

Les constructeurs et les builders assainissent les valeurs, donc une construction n'échoue jamais :

- `threshold_block_size` est contraint à un minimum de `3` (la valeur est un *rayon* — la fenêtre de comparaison fait `2 × taille + 1` pixels de large).
- `merge_threshold_ratio` est contraint dans `[0.0, 1.0]` ; `NaN` correspond au défaut `0.8`.
- `Binarization::sauvola(k)` remplace un `k` non fini par le défaut `0.2`.

<Code lang="rust" code={`use grider::GridConfig;

let config = GridConfig::new(1, 2.5, true);
assert_eq!(config.threshold_block_size, 3); // clamped up
assert_eq!(config.merge_threshold_ratio, 1.0); // clamped down`} />

## Valider les valeurs construites à la main

Les valeurs qui contournent le builder — littéraux de structure ou désérialisation — peuvent être hors limites. Appelez `validate()` avant l'extraction :

<Code lang="rust" code={`use grider::GridConfig;

assert!(GridConfig::default().validate().is_ok());
assert!(GridConfig { threshold_block_size: 0, ..GridConfig::default() }.validate().is_err());`} />

`validate()` signale le premier problème qu'il trouve sous forme de [`GridError::InvalidConfig`](/reference/errors/) : une taille de bloc nulle, un ratio de fusion non fini ou hors limites, ou un `k` Sauvola non fini.

## Vérifier vos modifications avec une superposition

Réglez la configuration en regardant la visualisation qu'elle produit — un appel par configuration candidate :

<Code lang="rust" code={`use grider::debug::save_image_with_grid;
use grider::drawing::GridDrawingConfig;

save_image_with_grid(&img, &grid, "output_with_grid.png", &GridDrawingConfig::default())
    .expect("Failed to save overlay");`} />

<Aside kind="tip">
    Exécutez la même boucle depuis le terminal à la place : `grider scan.png --block-size 15 --delta 2 --merge-ratio 0.9`
    réécrit `scan_with_grid.png` à chaque exécution, donc vous comparez les candidats sans recompiler.
</Aside>
