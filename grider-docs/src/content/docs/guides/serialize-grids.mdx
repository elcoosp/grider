This guide shows you how to serialize and deserialize every Grider data type with the default `serde` feature — including the JSON path of the command-line binary and the backward-compatibility rules introduced in 0.3.

## Prerequisites

- Grider with the default features (`serde` is enabled by default)

## Serialize a grid

`Grid`, `Row`, `Column`, `LineInfo`, `LineKind`, `GridConfig` and `Binarization` all derive `Serialize` and `Deserialize` when the `serde` feature is on:

<Code lang="rust" code={`use grider::{Grid, GridConfig};
use image::open;

let img = open("tests/large.png").unwrap();
let grid = Grid::try_from_image_with_config(&img, GridConfig::default()).unwrap();

let json = serde_json::to_string_pretty(&grid).unwrap();
println!("{json}");`} />

A `Grid` serializes to its two public fields, `rows` and `columns`:

<Code lang="json" code={`{
    "rows": [
  { "y": 0, "height": 11, "kind": "Empty" },
  { "y": 11, "height": 18, "kind": "Empty" },
  { "y": 46, "height": 177, "kind": "Full" }
    ],
    "columns": [
  { "x": 0, "width": 4, "kind": "Empty" }
    ]
}`} />

The JSON above is the real beginning of the output that the 0.3.0 CLI prints for the repository's `tests/large.png` fixture.

## Round-trip a configuration

Deserialization restores a `GridConfig` exactly — including a Sauvola binarization:

<Code lang="rust" code={`use grider::GridConfig;

let config = GridConfig::builder().sauvola(0.45).build();
let json = serde_json::to_string(&config).unwrap();
let parsed: GridConfig = serde_json::from_str(&json).unwrap();
assert_eq!(parsed, config);`} />

## Keep legacy configs deserializable

0.3 added the `binarization` field to `GridConfig`. The field carries `#[serde(default)]`, so JSON written by a 0.2 program still deserializes:

<Code lang="rust" code={`use grider::GridConfig;

let legacy = r#"{
    "threshold_block_size": 12,
    "threshold_delta": 0,
    "merge_threshold_ratio": 0.8,
    "enable_parallel": true
}"#;
let parsed: GridConfig = serde_json::from_str(legacy).unwrap();
assert_eq!(parsed, GridConfig::default());`} />

<Aside kind="caution">
    The same addition breaks **struct literals**: `GridConfig { threshold_block_size: 12, … }` no longer
    compiles without the `binarization` field. Add the field or finish the literal with
    `..GridConfig::default()`.
</Aside>

## Print JSON from the CLI

<Code lang="bash" code={`grider tests/large.png --json --quiet`} />

`--json` prints the pretty JSON of the whole grid to stdout and skips the overlay file. Pair it with `--quiet` when a machine reads the output, because the human-readable summary goes to stdout too.

<Aside kind="note">
    Built without the `serde` feature, the binary prints
    `Skipping JSON output: built without the 'serde' feature` and exits successfully.
</Aside>
