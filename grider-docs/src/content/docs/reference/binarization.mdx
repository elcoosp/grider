Binarization turns the grayscale image into a black-and-white picture where background is white (`255`) and content is black (`0`); the extraction pipeline then looks for scan lines made purely of background pixels. Both algorithms run in `O(width × height)` regardless of the window radius, with `O(width × radius)` extra memory.

## The enum

```rust
pub enum Binarization {
    AdaptiveMean,
    Sauvola { k: f32 },
}
```

Derives `Debug`, `Clone`, `Copy`, `Default`, `PartialEq` (and `Serialize`/`Deserialize` with the `serde` feature). The default variant is `AdaptiveMean`.

### AdaptiveMean

The adaptive mean threshold (Bradley & Roth, 2005). A pixel is background when it is at least as bright as the mean of its window minus [`threshold_delta`](/reference/grid-config/). The output is **bit-for-bit identical** to `imageproc::contrast::adaptive_threshold`, verified by property tests.

### Sauvola

The Sauvola & Pietikäinen (2000) threshold for degraded documents. The local threshold follows the mean **and** the standard deviation of the window, which copes with uneven illumination and low contrast.

| Field | Meaning |
| :--- | :--- |
| `k` | Sensitivity to local contrast, typically in `[0.1, 0.5]`; `0.2` is a good default and the fallback for non-finite values. [`threshold_delta`](/reference/grid-config/) is unused by this method |

The standard deviation uses the dynamic range constant `SAUVOLA_DYNAMIC_RANGE = 128.0` — for 8-bit grayscale images the deviation is bounded by `255 / 2`, and `128` is the conventional rounding of that bound.

## Constants

| Constant | Value | Meaning |
| :--- | :--- | :--- |
| `SAUVOLA_DEFAULT_K` | `0.2` | Fallback for non-finite `k` |
| `SAUVOLA_DYNAMIC_RANGE` | `128.0` | Standard-deviation range `R` in the Sauvola formula |
| `MIN_BLOCK_RADIUS` (binarize module) | `1` | Lower bound for the window radius |

## Functions

| Function | Signature | Behavior |
| :--- | :--- | :--- |
| `binarize` | `(img: &GrayImage, config: &GridConfig) -> GrayImage` | Dispatches on `config.binarization` — the entry the pipeline uses |
| `adaptive_mean_threshold` | `(img: &GrayImage, block_radius: u32, delta: i32, parallel: bool) -> GrayImage` | Streaming sliding-window integral image (Bradley & Roth); bit-identical to `imageproc`, 1.6–3.1× faster |
| `sauvola_threshold` | `(img: &GrayImage, block_radius: u32, k: f32, parallel: bool) -> GrayImage` | Integral-image Sauvola (Shafait et al. 2008) for degraded documents |

## Memory model

The adaptive mean binarizer never materializes a whole integral image. Peak extra memory is two streaming bands, `O(width × radius)`:

| Image | Whole integral image (`u32`) | Streaming ring (`f64`) |
| :--- | ---: | ---: |
| 1000 × 1000, r = 12 | ~4 MB | ~104 KB |
| 4000 × 4000, r = 12 | ~64 MB | ~1.7 MB |
| 4000 × 4000, r = 64 | ~64 MB | ~8.3 MB |
